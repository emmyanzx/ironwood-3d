# Ironwood — 3D Mech Battlefield

A playable 3D desert mech battlefield built with Three.js for [start.ng](https://start.ng). Pilot the transforming **AEGIS** war robot across windswept sand dunes, morph into a high-speed 6-wheel combat car, fire 5 distinct weapon styles, and deploy allied hover drones, armored wingman cars, and autonomous missile pods against escalating enemy mech waves.

## Controls
- **W A S D / Arrows** — Move mech or drive 6-wheel car
- **Mouse + Left Click** — Aim & fire active weapon
- **Right Click (hold)** — Frontal energy Brace Shield
- **T** — Transform between Heavy War Mech & 6-Wheel Combat Car
- **G / H / J / K / L** — Switch weapon styles (Aegis, Bulwark, Twin Fire, Hammerfall, Quake)
- **F** — Homing missile salvo
- **Shift + A / D** — Thruster side-roll dodge
- **X / Z** — Siege Mode / Strider Mode
- **Q** — Cycle target lock
- **4** — Deploy Support Squad (2 drones + 3 cars)
- **5** — Deploy Missile Pod (20s)
- **Esc** — Settings, Eco/Bloom graphics toggle, and Leaderboard
